# Krushnal Patil — Cinematic Portfolio

A cinematic black-and-gold React + TypeScript portfolio for Krushnal Patil.

## Stack
- React + TypeScript
- Vite
- Framer Motion
- Lenis smooth scrolling
- CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```
